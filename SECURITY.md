# Security Policy / 安全策略

## Supported versions / 支持版本

Only the latest published version receives security fixes. 当前仅维护最新发布版本的安全修复。

## Reporting / 报告漏洞

请通过 GitHub 的 [Private Vulnerability Reporting](https://github.com/Niall-Young/Skill-manager/security/advisories/new) 私下报告安全问题，不要创建公开 Issue。请包含受影响命令、最小复现、潜在文件系统影响和建议修复（如有）。

Please use GitHub [Private Vulnerability Reporting](https://github.com/Niall-Young/Skill-manager/security/advisories/new) instead of a public issue. Include the affected command, a minimal reproduction, potential filesystem impact, and a suggested fix when available.
